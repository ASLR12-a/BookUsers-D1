# BookUsers

Aplicación de escritorio desarrollada en Java con interfaz gráfica Swing/AWT para la gestión de usuarios, consulta de registros, generación de reportes en PDF y visualización de créditos.

## Funcionalidades principales
- **Gestión de usuarios (`CrearUsuarios`):** Creación de usuarios y actualización de registros de usuarios.
- **Listado y persistencia (`ListaUsuarios`):** Carga, almacenamiento y visualización de los usuarios registrados.
- **Exportación a PDF (`GeneradorPDF`):** Generación de documentos PDF con la información de los usuarios con el ArrayList.
- **Menú principal (`VersionUni`):** Menu con varias ventanas
- **Créditos (`Creditos`):** Ventana con los datos de nosotros - Leidy Niño y Adrian Lopez
## herramientas
- **Lenguaje:** Java
- **Interfaz gráfica:** Java Swing / AWT (IntelliJ UI Designer)
- **IDE:** IntelliJ IDEA
- **Control de versiones:** Git y GitHub
